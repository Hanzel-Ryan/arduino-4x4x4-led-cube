# Arduino-Controlled 4×4×4 LED Cube

A 4×4×4 LED cube consisting of 64 LEDs, assembled and soldered during a hands-on workshop organized by IEEE and the XMUM Robotics Club.

## My Contribution

- Assembled and aligned four layers containing 64 LEDs
- Connected the common grounds for each layer
- Soldered the LED structure to the controller board
- Uploaded and tested the Arduino firmware
- Checked the completed circuit for poor joints and accidental shorts

## What I Learned

This project gave me practical experience in controlling the amount of flux and solder applied to each connection, recognizing cold joints and solder bridges, and maintaining consistent LED alignment throughout a repetitive assembly process.

I also learned an important safety lesson after accidentally touching a heated metal section of the soldering equipment. This reinforced the importance of proper tool handling, workspace organization, and treating nearby metal surfaces as hot.

## Firmware Attribution

The Arduino firmware included in this repository is ICStation example code provided during the workshop. I did not author the original firmware. It is included to document the software used to operate and test my hardware build, with the original attribution retained.
